# Feniks Radio

A Flutter app for listening to Feniks Radio live stream, with user accounts, Feniks points, leaderboard, and badges.

## Features

- **Live radio** – Stream Feniks Radio with play/pause and volume control
- **Auth** – Register and log in with username and password (no email required)
- **Feniks points** – Earn points from listening time and badges; view breakdown (badges earned, badge points, minutes listened, listening points)
- **Leaderboard** – Top 10 by Feniks points; your rank when logged in
- **Badges** – Achievements for listening milestones, sessions, and more
- **Profile** – View your points and account; logout
- **Settings** – Dark mode, notifications, and app info
- **Favorites** – Save and manage favorite songs
- **Ether messages** – Placeholder for future community messages

## Prerequisites

- [Flutter](https://flutter.dev/docs/get-started/install) (SDK ^3.8.1)
- Firebase project with:
  - Authentication (Email/Password enabled)
  - Cloud Firestore
- For Android: `google-services.json` in `android/app/`
- For iOS: `GoogleService-Info.plist` in `ios/Runner/`

## Setup

1. **Clone and enter the project**
   ```bash
   cd feniksflutter
   ```

2. **Install dependencies**
   ```bash
   flutter pub get
   ```

3. **Firebase**
   - Create a Firebase project at [Firebase Console](https://console.firebase.google.com/)
   - Add Android and/or iOS apps and download config files to the paths above
   - Enable Email/Password sign-in and create Firestore database with your desired rules

4. **Generate app icons** (optional; uses `lib/assets/png/app_icon.png`)
   ```bash
   dart run flutter_launcher_icons
   ```

## Run

```bash
flutter run
```

For release builds:

```bash
flutter build apk        # Android
flutter build ios        # iOS (requires macOS and Xcode)
```

## Project structure

- `lib/main.dart` – App entry, routes, providers
- `lib/pages/` – Screens (home, leaderboard, profile, settings, login, welcome, etc.)
- `lib/widgets/` – Reusable UI (player card, footer, badges, etc.)
- `lib/models/radio_player_model.dart` – Player state, points, badges, listening stats
- `lib/services/` – Auth, Firestore, metadata (now playing), notifications
- `lib/theme/` – App theme and dark mode
- `lib/assets/` – Images and assets (e.g. logos, background, app icon)

## Environment

- Stream URL and metadata are configured in the app (e.g. `lib/models/radio_player_model.dart`, `lib/services/metadata_service.dart`). Replace with your own endpoints/keys if needed.
- Firebase config is loaded from `firebase_options.dart` (generated by FlutterFire CLI if you use it) or from the config files in `android/app/` and `ios/Runner/`.
